# CaLeap V21 — Real Vision Inference

V21 replaces the placeholder/unavailable-only path with a **real device inference path** using the existing Google ML Kit Image Labeling dependency.

## Important quality boundary

ML Kit's default image-labeling model is a **general visual model**, not a dedicated food classifier. V21 therefore does not claim food-level accuracy from it.

The output is:

```text
PHOTO
→ REAL ON-DEVICE VISION INFERENCE
→ LABEL CANDIDATES
→ CANDIDATE FUSION
→ FOOD CATALOG / FOOD GRAPH MATCH
→ CONFIDENCE POLICY
→ USER REVIEW WHEN NEEDED
```

Nutrition is never generated by the vision model.

## Why this is a real improvement

- Actual on-device inference path is now connected to the canonical V20 adapter.
- Model ID/version are preserved.
- Inference duration is recorded.
- Errors and low confidence remain explicit.
- Generic labels are mapped to food candidates only when catalog terms match.
- Existing capture UI can continue using `FoodVisionAnalyzer`.

## What V21 does NOT claim

It is not a dedicated global food classifier and it is not a validated medical/nutrition system.

The next specialized model should be added only after its actual mobile artifact, license, conversion/runtime compatibility, checksum and validation data are verified.
