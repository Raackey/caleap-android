# V8.3.4 Research Notes

Android documentation reviewed on 2026-09-19:
- Jetpack DataStore is the recommended asynchronous transactional preference storage; the existing project already carries DataStore, but this release keeps the small local library implementation isolated to avoid a dependency/compiler change before the APK build gate.
- Android Sharesheet guidance recommends ACTION_SEND with Intent.createChooser() for general external sharing.
- Storage Access Framework / app-specific storage guidance supports user-controlled file access without broad storage permissions.

The implementation intentionally avoids changing the Kotlin/Compose toolchain in this release.
