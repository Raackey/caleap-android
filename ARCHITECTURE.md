# Android V8.3.1 Architecture

Android is a client, not a second W2P brain.

```
Android UI
  ↓
W2P API client
  ↓
V8.3 Dynamic Intelligence
  ├─ Intent & Goal
  ├─ Dynamic Planner / Task Graph
  ├─ Capability routing
  ├─ Research Intelligence
  ├─ Creation Intelligence
  ├─ Prompt Intelligence
  ├─ Prompt Quality
  ├─ Result Intelligence
  └─ Auto-Fix / Creation Jobs
```

The Result Workspace is first-class. Advanced intelligence is progressively disclosed rather than consuming the primary result area.
