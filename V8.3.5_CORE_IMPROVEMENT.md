# Word2Prompt Android V8.3.5 — Core Improvement

V8.3.5 strengthens the actual creation loop instead of adding cosmetic screens.

## Core changes
- Usage is checked and consumed before a prompt-generation run.
- Creation pipeline has explicit stages: access → context → research → creative plan → prompt → quality → ready.
- Pipeline status and elapsed time are visible to the user.
- Source-of-truth image input is supported from the Android Create workspace and forwarded to the W2P Intelligence Layer.
- Fallback remains deterministic when model-backed stages are unavailable.
- Existing V8.3 Dynamic Intelligence, V8.2.6 No-GPU architecture, Result Intelligence, Auto-Fix, Library, account and billing contracts are preserved.

## Verification boundary
Static/source checks are performed in this environment. Android Gradle compilation must still be proven by GitHub Actions, followed by installation and phone testing.
