Clean Android foundation for CaLeap.

- Gradle 8.11.1
- Android Gradle Plugin 8.10.1
- Kotlin 2.0.21
- JDK 17
- compileSdk 36

- applicationId com.maisor.caleap

The GitHub workflow is intentionally named `.github/workflows/main.yml`.
